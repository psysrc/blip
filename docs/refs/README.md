# Reference Programs

The documents in this folder contain example Blip programs along with their Blip Intermediate Representation (Blip IR)
and example program executions with string inputs and outputs. If you're just getting started with Blip, this is a great place to start,
as you can expose yourself to lots of example programs and see exactly what the expected inputs and outputs of each program should be.

**The documentation here is also the core Blip test suite!**
They are automatically parsed and executed in the test suite, meaning they are always up to date with the code.

Some programs are intentionally ill-formed and do not compile. The error they raise is recorded in a `#### Error` section.

If you're not sure where to start, check out [Basic Programs](basic_programs.md) first.
Then check out some of the more advanced features such as [Decomposition](decomposition.md).
