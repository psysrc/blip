# Blip Syntax

## String Literals

A literal string defined in the program.

Example:

```plaintext
"A literal string"
```

## Variables

An arbitrary number of variables can be used in a Blip program to help organise data, just like any other programming
language.

Example:

```plaintext
name = "John"
```

## IN and OUT

`IN` and `OUT` are special identifiers that represent the input and output of a Blip program, respectively.
A list of strings comes `IN` to the program, and a list of strings go `OUT` of the program.
